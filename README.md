# Ирина Суморока — демонстрация личного сайта

Статическая страница на русском языке. Slug: `irina-sumoroka-demo`. Без сборки, сервера приложения, форм, оплаты или календаря. Открыть `index.html` либо использовать любой статический хостинг. Для браузерной проверки: `python -m http.server 4223`.

## Дизайн

Редакционная композиция: тёмный лесной цвет, бумажный фон, медь и сливочно-жёлтый. Основной объект — настоящий портрет. Мотив двух соприкасающихся форм поддерживает тему контакта и границ. Крупный Cormorant и спокойный Manrope; локальные WOFF2, лицензии OFL находятся рядом с ними в assets. На мобильном экране текст предшествует портрету, все блоки выстраиваются вертикально. Движение ограничено состояниями ссылок и кнопок; reduced motion отключает переходы.

Последовательность: знакомство → выбор темы → форматы → проверяемый профессиональный контекст → вопросы → личное сообщение. Исключены отзывы, гарантии результата, неподтверждённые дипломы, актуальные цены и даты групп. Переключатель тем использует aria-pressed и live-region; FAQ — нативные details/summary; текст виден без JavaScript.

## Контроль перед размещением

Проверить имя и содержание с Ириной; согласовать фотографию и профессиональное описание; подтвердить актуальность контакта. Персональные данные посетителей сайт не собирает. Внешние ссылки с target blank используют rel noopener noreferrer.

Проверены выбор второй темы, Enter на третьей теме, состояние aria-pressed, раскрытие FAQ, пять ссылок с точным адресом VK. При выключенном JS видимы заголовок и дополнительные темы; при reduced-motion computed scroll-behavior = auto. Финальные desktop/mobile full-page скриншоты визуально просмотрены. Доказательства и воспроизводимый скрипт сохранены в игнорируемой папке `.work`.

Визуальный контроль: на первом экране различимы имя, профессия, реальный портрет и действие; сетка асимметричная, страницы на мобильном переходят в последовательный вертикальный рассказ. Проверяемые сведения отделены от редакционного текста, доступность набора в группы не обещана. Крупная типографика, рамка портрета и мотив контакта сохраняются на обоих размерах.
